Android music player

Your music. Your Drive. Played loud.

PlayitLoud streams your songs straight from your own Google Drive. There's no server and no subscription, and nothing stays on your phone except a small cache that cleans itself.

How it works

From your Drive to your ears, in five steps.

Every folder in PlayitLoud Music is a playlist. When you press play, this is the path a song takes.

Your Google Drive

Songs and .lrc lyrics live in your own account.

Google sign-in

A short-lived token, kept in memory and refreshed silently.

Byte-range stream

Only the bytes needed right now, so a 500 MB FLAC starts instantly.

Smart cache

Intro, next song and recent songs are already on the phone.

Sound engine

Bass, harmonics and a limiter, then out loud.

The cache

Feels local. Isn't.

Playback keeps going through short connection drops because the next song is already downloaded. Pick a tier to see what it holds.

Sound engine

Bass you can feel, even on a phone speaker.

A custom audio processor sits between the decoder and the speaker. Try the same presets and controls the app has.

An illustration of the shape these settings give the sound: a low-shelf boost below Freq, Punch adding harmonics an octave and more above the bass, and Preamp moving everything up or down. A smooth limiter keeps peaks from crackling.

Everything else

Small app. Big sound.

A player that moves

A spinning vinyl with rings that react to the music, and a waveform seek bar that learns each song's shape as you listen.

Synced lyrics

Drop a .lrc file next to a song in Drive and the lyrics scroll in time.

Uploads of any size

Resumable 8 MB chunks that continue after a dropped connection, a killed app or a reboot.

Folders are playlists

Every subfolder of PlayitLoud Music becomes a playlist. Add songs from the app or from Drive anywhere.

Rides out dead zones

With the next song prefetched, a 40-second connection drop goes unnoticed.

About 2 MB

R8 shrinking strips unused code and resources, so the APK stays tiny.

Privacy and security

Your music never leaves your account.

No server

The app talks only to Google's APIs. No backend, no analytics, no tracking.

No secrets in the code

No signing key, client ID or token. You register your own copy in your own Google Cloud project.

Google's own sign-in

Google's account picker, with the token held in memory and refreshed silently.

Few permissions

Internet, notifications and background playback. No storage, contacts, location, camera or mic.

Docs

Run your own copy in about 15 minutes.

You need a Google account and either GitHub (to build in the cloud, no laptop needed) or Android Studio.

Step 1

Create your signing key

On any computer with Java installed:

keytool -genkeypair -v -keystore playitloud.jks -alias playitloud \
  -keyalg RSA -keysize 4096 -validity 10000
keytool -list -v -keystore playitloud.jks -alias playitloud | grep SHA1
Keep playitloud.jks and its passwords private, and never commit them. Note the SHA-1 line for step 2.
Step 2

Set up Google Cloud

  1. In the Google Cloud console, create a project and enable the Google Drive API.
  2. In Google Auth Platform, create the consent screen: External, status Testing, and add your Gmail under Test users.
  3. Under Data Access, add the scope https://www.googleapis.com/auth/drive.
  4. Under Clients, create an Android client with package name dev.wave.player and your SHA-1.

No client ID or secret goes into the code. Google recognises your app by its package name and your key's SHA-1.

Step 3

Build the app

In the cloud with GitHub Actions. Fork the repository, then add four secrets under Settings → Secrets and variables → Actions:

SecretValue
PLAYITLOUD_KEYSTORE_BASE64Output of base64 -w0 playitloud.jks
PLAYITLOUD_KEYSTORE_PASSWORDYour keystore password
PLAYITLOUD_KEY_ALIASplayitloud
PLAYITLOUD_KEY_PASSWORDYour key password

Push to main or run Actions → Build APK. The signed playitloud.apk appears under Releases → latest in your fork.

Or with Android Studio. Set the same values as environment variables, open the project and press Run:

export PLAYITLOUD_KEYSTORE_PATH=/path/to/playitloud.jks
export PLAYITLOUD_KEYSTORE_PASSWORD=...
export PLAYITLOUD_KEY_ALIAS=playitloud
export PLAYITLOUD_KEY_PASSWORD=...
Step 4

Connect and play

Install the APK, tap Connect Google Drive and pick your test Gmail. On "Google hasn't verified this app", tap Continue, which is normal in Testing mode. The app creates this folder:

PlayitLoud Music/          -> playlist "Library"
  Song A.mp3
  Song A.lrc               -> synced lyrics (same name as the song)
  Road Trip/               -> playlist "Road Trip"
    Song B.flac

Add songs with Add songs in the app, or drop files into these folders from Drive on any device and tap refresh.
